# Exam Ready React Template

This is a clean copy-and-edit project based on your gym page patterns.

## Fast Edit Order

1. Open `src/data/siteData.js`.
2. Change `siteInfo`, `programs`, `coaches`, `planDetails`, and `authContent`.
3. Replace images in `src/assets/images`.
4. Change colors/classes inside components only if the exam asks for a different style.

## Features Included

- Responsive navbar with mobile menu
- Login and signup popup
- Hero buttons that open popups
- Program cards using `.map()`
- Detail popup when clicking cards
- Dashboard full-screen modal
- Nested add-program popup inside dashboard
- Add, duplicate-disable, and cancel/remove logic
- Pricing modal and footer sections

## Run

```bash
cd exam-ready-template
npm install
npm run dev
```

If you are running from inside the original `TAILWIND` folder and dependencies are already installed there, `npm run dev` may work immediately because this folder uses the same Vite/React dependencies.
